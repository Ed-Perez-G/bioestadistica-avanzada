1. Fundamentos de la selección de variables

Propósito de la selección de predictores

Tenemos un desenlace \(Y\) y muchas variables candidatas. ¿Cuáles incluir?

  • Explicar: estimar el efecto de una exposición controlando confusores (¿el tabaquismo reduce el peso al nacer?).
  • Describir: identificar qué factores se asocian con \(Y\) (¿qué variables clínicas se asocian con la bilirrubina?).
  • Predecir: construir el modelo que mejor anticipe \(Y\) en pacientes nuevos (Shmueli 2010).

Antes de elegir un método hay que responder: ¿para qué quiero el modelo? La respuesta cambia el método correcto (Heinze, Wallisch, y Dunkler 2018).

El problema: demasiados modelos posibles

Con \(k\) candidatas hay \(2^k\) modelos posibles (cada variable entra o no).

Revisarlos todos (“mejor subconjunto”) es posible con pocas variables. Con muchas, los algoritmos secuenciales recorren solo un camino entre ellos (James et al. 2021).

Parsimonia, interpretabilidad y sobreajuste

  • Parsimonia: entre modelos que explican lo mismo, el más simple; además es más interpretable (Denis 2020).
  • Se debe privilegiar los modelos interpetables. Menos variables más interpretabilidad (Harrell 2015).
  • Cuando se separan en conjunto de entrenamiento y validadción se debe de cuidar el sobreajuste

Selección para inferencia vs. para predicción

Inferencia (explicar) Predicción
Pregunta ¿Cuál es el efecto de X sobre Y? ¿Qué tan bien anticipo Y?
Qué importa Coeficientes insesgados con IC válidos Error de predicción en datos nuevos
Variables Confusores definidos por teoría (DAG) Las que mejoren la predicción validada
Selección automática Desaconsejada como estrategia principal Aceptable si se valida
Métodos típicos Conocimiento previo, purposeful, cambio en el estimador LASSO, elastic net, validación cruzada

Un algoritmo no sabe qué es un confusor, un mediador o un colisionador (Parte 2 y 3). Puede eliminar un confusor o retener un mediador (Heinze y Dunkler 2017; VanderWeele 2019).

Siempre tomar en cuenta

  • El objetivo del modelo (explicar vs. predecir) define qué variables entran
  • Seleccionar con conocimiento previo / DAG, no con p-valores ni stepwise
  • Incluir confusores; no ajustar por mediadores ni colisionadores
  • Interacciones: solo con hipótesis a priori (requieren mucho más n)
  • Tamaño de muestra robusto
  • Más variables de las que el n soporta → sobreajuste y coeficientes inestables
  • Colinealidad: infla errores estándar (revisar VIF)
  • Datos faltantes: más variables pueden reducir el n efectivo
  • No hay un número exacto; ~10–20 por parámetro es una guía, no una regla
  • Revisar los IC: si son muy amplios (o absurdos), probablemente falta información
    • Pero un IC razonable no garantiza que el n sea suficiente (puede haber sobreajuste o sesgo con IC estrechos)

2. Métodos de selección secuencial

Idea general

  • En cada paso se compara un criterio (valor p, AIC o BIC) y se elige el mejor movimiento (James et al. 2021).
  • En R: step() (base) o MASS::stepAIC() usan AIC por defecto (Venables y Ripley 2002).

Ejemplo: ¿qué factores se asocian con el peso al nacer?

# Modelo nulo (solo intercepto) y modelo completo (todas las candidatas)

completo <- lm(bwt ~ age + lwt + race + smoke + ptl + ht + ui + ftv, data = bw)

  • Ventaja: evalúa cada variable en presencia de todas las demás (no pierde variables que solo importan juntas) (Heinze, Wallisch, y Dunkler 2018).

2.3 Stepwise (en ambas direcciones)

En cada paso evalúa agregar una variable nueva o quitar una que ya está.

m_stepwise <- step(nulo, scope = formula(completo), direction = "both", trace = 0)
formula(m_stepwise)

# Con MASS::stepAIC() el resultado es el mismo
m_stepAIC <- stepAIC(completo, direction = "both", trace = 0)

Ventajas y limitaciones de los métodos secuenciales

Ventajas Limitaciones
Rápidos y automáticos Recorren un solo camino: no garantizan el “mejor” modelo
Reproducibles Resultados inestables: pequeños cambios en los datos cambian las variables elegidas
Útiles para explorar muchas candidatas Valores p, EE e IC del modelo final son demasiado optimistas
Disponibles en todo software Coeficientes inflados (sesgo de selección)
Ignoran confusión, mediación y plausibilidad biológica

Estas limitaciones están bien documentadas desde hace décadas (Harrell 2015; Whittingham et al. 2006; Smith 2018). Los revisaremos en el bloque 5.

3. Criterios estadísticos para la selección

El criterio clásico: entra la variable con menor p (si p < α de entrada); sale la de mayor p (si p > α de salida).

3.2 Criterio de información de Akaike (AIC)

\[AIC = n\ln\left(\frac{SCE}{n}\right) + 2k \qquad \text{(regresión lineal)}\]

  • Ajuste (primer término) + penalización por número de parámetros \(k\) (Akaike 1974).
  • Menor AIC = mejor balance. Solo se compara entre modelos ajustados con los mismos datos.
  • \(\Delta AIC < 2\): modelos prácticamente equivalentes (Burnham y Anderson 2002).
  • Pensado para predicción: tiende a incluir alguna variable de más.
m_pima_completo <- lm(glu ~ npreg + bp + skin + bmi + ped + age, data = Pima.tr)
m_pima_aic <- step(m_pima_completo, trace = 0)   # k = 2 (AIC) por defecto
formula(m_pima_aic)
glu ~ bp + bmi + age

3.3 Criterio de información bayesiano (BIC)

\[BIC = n\ln\left(\frac{SCE}{n}\right) + k\ln(n)\]

  • La penalización crece con \(n\): con \(n \geq 8\), \(\ln(n) > 2\) → BIC es más estricto que AIC (Schwarz 1978).
  • Favorece modelos más simples; pensado para identificar el modelo “verdadero” si está entre los candidatos.
n_pima <- nrow(Pima.tr)
m_pima_bic <- step(m_pima_completo, k = log(n_pima), trace = 0)   # k = log(n) → BIC
formula(m_pima_bic)
glu ~ bmi + age

AIC retuvo bp (presión diastólica); BIC la eliminó. ¿Cuál elegir? Depende del objetivo y del conocimiento previo.

4. Métodos de regularización

Idea: encoger en lugar de quitar

Los métodos secuenciales deciden dentro/fuera. La regularización ajusta todas las variables, pero penaliza los coeficientes grandes (James et al. 2021; Hastie, Tibshirani, y Friedman 2009):

\[\text{minimizar: } \underbrace{\sum (y_i - \hat y_i)^2}_{\text{ajuste}} + \underbrace{\lambda \times \text{penalización}(\beta)}_{\text{encogimiento}}\]

  • \(\lambda = 0\): regresión lineal ordinaria.
  • \(\lambda\) grande: coeficientes cada vez más cerca de 0.
  • \(\lambda\) se elige por validación cruzada.
  • Útiles con muchas variables, variables correlacionadas o \(p > n\) (genómica, transcriptómica).

Trayectorias de los coeficientes

Datos pbc: log(bilirrubina) con 15 candidatas. De derecha a izquierda aumenta la penalización.

4.1 Ridge Regression (L2)

  • Penalización: \(\lambda\sum\beta_j^2\) (Hoerl y Kennard 1970).
  • Encoge todos los coeficientes, pero ninguno llega a 0 → no selecciona variables.
  • Útil con colinealidad: estabiliza coeficientes de predictores correlacionados.
  • Ejemplo: predecir un rasgo cuantitativo con miles de SNPs de efecto pequeño (base de algunos puntajes poligénicos).

4.2 LASSO Regression (L1)

  • Penalización: \(\lambda\sum|\beta_j|\) (Tibshirani 1996).
  • Encoge y lleva algunos coeficientes exactamente a 0 → selecciona variables.
  • Ejemplo: de 20 000 genes, elegir una firma de expresión pequeña asociada a un fenotipo.
  • Limitación: entre variables muy correlacionadas tiende a elegir una al azar.

4.3 Elastic Net (L1 + L2)

  • Combina ambas penalizaciones con un parámetro de mezcla \(\alpha\) (Zou y Hastie 2005):
    • \(\alpha = 0\) → ridge · \(\alpha = 1\) → LASSO · \(0 < \alpha < 1\) → elastic net.
  • Selecciona variables y mantiene juntos grupos de predictores correlacionados (genes de una misma vía, SNPs en desequilibrio de ligamiento).
Método Penalización ¿Selecciona? Mejor cuando…
Ridge L2 No Muchas variables, todas aportan un poco; colinealidad
LASSO L1 Sí Pocas variables realmente importantes
Elastic net L1 + L2 Sí Grupos de variables correlacionadas; \(p \gg n\)

Precaución: los coeficientes están sesgados hacia 0 a propósito; no se usan para inferencia clásica (IC, p) (James et al. 2021).

5. Validación y estabilidad de la selección

5.1 Validación cruzada

  • Se divide la muestra en \(k\) partes; se ajusta con \(k-1\) y se evalúa en la parte no usada; se repite \(k\) veces (James et al. 2021).
  • Estima el error en datos nuevos. Sirve para elegir \(\lambda\) y para comparar estrategias de selección.

5.2 Bootstrap: ¿qué tan estable es la selección?

Repetimos backward (AIC) en 200 muestras bootstrap de birthwt y contamos cuántas veces se elige cada variable (Sauerbrei y Schumacher 1992; Austin y Tu 2004).

Variables elegidas en > 80 % de las réplicas son estables; las que aparecen 20–50 % dependen del azar de la muestra. El modelo “final” de un solo stepwise oculta esta incertidumbre.

5.3 Stability Selection

  • Idea: repetir la selección (habitualmente LASSO) en muchas submuestras (50 % de los datos) y quedarse con las variables elegidas en una alta proporción (p. ej., > 60–80 %) (Meinshausen y Bühlmann 2010).
  • Controla el número esperado de falsos positivos; muy usada en genómica de alta dimensión.

6. Aplicaciones prácticas en R. Codigo de ejemplo.

6.1 step() y stepAIC(): argumentos clave

6.2 Regularización con glmnet

y_pbc <- pbc2$log_bili

set.seed(123)
cv_lasso <- cv.glmnet(X_pbc, y_pbc, alpha = 1)     # LASSO con validación cruzada de 10 pliegues
plot(cv_lasso)                                      # error de VC según lambda

La puerta a la regresión logística

Todo lo anterior funciona con un desenlace binario cambiando una línea:

# Selección secuencial en regresión logística
completo_log <- glm(low ~ age + lwt + race + smoke + ptl + ht + ui + ftv,
                    data = birthwt, family = binomial)
step(completo_log, direction = "backward")

# LASSO logístico
cv.glmnet(X, y_binaria, alpha = 1, family = "binomial")

Próximo tema: regresión logística. Los criterios (AIC, BIC, LRT), la validación y las advertencias sobre la selección automática son los mismos.
