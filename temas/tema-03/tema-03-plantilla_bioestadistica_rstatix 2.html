1 Introducción

En esta clase aprenderemos a realizar pruebas de hipótesis de forma sistemática en R utilizando dos paquetes complementarios:

  • rstatix: Un paquete que facilita los cálculos estadísticos y proporciona resultados en formato tibble (tidy).
  • ggstatsplot: Un paquete que integra pruebas de hipótesis directamente en visualizaciones de ggplot2.

2 Introducción a rstatix: ¿Cómo funciona este paquete?

2.1 Filosofía de rstatix

El paquete rstatix fue diseñado bajo la filosofía tidy data de R. Sus características principales son:

  1. Resultados en formato tibble: Los resultados estadísticos se presentan como tablas ordenadas, no como listas complejas.
  2. pipes (%>% o |> ): Compatible con el flujo de trabajo de tidyverse.
  3. Nombres consistentes: Columnas intuitivas como statistic, p.value, df, estimate, conf.low, conf.high.
  4. Tamaño del efecto automático: Muchas funciones calculan automáticamente medidas de efecto (eta squared, Cohen’s d, etc.).

2.2 Estructura general de una función rstatix

# Estructura típica:
# datos %>%
#   funcion_estadistica(formula = variable_respuesta ~ variable_explicativa)

Por ejemplo, para una prueba de t de dos muestras independientes:

birthwt %>%
  t_test(bwt ~ smoke, detailed = T)  # peso del bebé ~ tabaquismo
# A tibble: 1 × 15
  estimate estimate1 estimate2 .y.   group1   group2    n1    n2 statistic     p
*    <dbl>     <dbl>     <dbl> <chr> <chr>    <chr>  <int> <int>     <dbl> <dbl>
1     284.     3056.     2772. bwt   No fuma… Fumad…   115    74      2.73 0.007
# ℹ 5 more variables: df <dbl>, conf.low <dbl>, conf.high <dbl>, method <chr>,
#   alternative <chr>

Note que: - rstatix devuelve un tibble con columnas claras. - Si especifica detailed = TRUE, obtiene información adicional. - Puede encadenar operaciones con %>% antes y después. - Note el _, esto permite diferenciar las funciones de rstatix del paquete base de R

3.1.3 3. Prueba de Chi-Cuadrado con rstatix

rstatix no es la mejor opción para la prueba de Chi-Cuadrado. Aún así vamos a revisar como realizarla.

3.1.3.1 3.1 Evaluación de supuestos

Antes de realizar la prueba, evaluamos el supuesto de frecuencias esperadas:

# El supuesto: todas las frecuencias esperadas ≥ 5
# Chi-cuadrado es robusto cuando se cumple este supuesto
table1 <- table(birthwt$low, birthwt$ht)
chisq.test(table1, correct = T)->resultado1

3.1.4 3.3 Tamaño del Efecto: V de Cramér

Necesita la librería rcompanion

# Calcular V de Cramér (medida de asociación)
# V = √(χ² / (n × (min(k,r) - 1)))
# donde k = # de columnas, r = # de filas

rcompanion::cramerV(table1)
Cramer V 
  0.1524 
# Interpretación de V de Cramér (criterios de Cohen):
# < 0.1: efecto negligible
# 0.1 - 0.3: efecto pequeño
# 0.3 - 0.5: efecto mediano
# > 0.5: efecto grande

Interpretación del tamaño del efecto: - V de Cramér mide la fuerza de la asociación entre dos variables categóricas. - Rango: 0 (sin asociación) a 1 (asociación perfecta).

3.1.5 3.4 Intervalos de Confianza

Para asociaciones entre variables categóricas, reportamos la Razón de Odds (OR) con su IC 95%:

# Crear tabla 2x2
tabla_2x2 <- table(birthwt$low, birthwt$ht)
print("Tabla 2x2:")
[1] "Tabla 2x2:"
print(tabla_2x2)
             
              No hipertensión Hipertensión
  Peso Normal             125            5
  Bajo Peso                52            7
# Calcular OR manualmente (método frecuentista)
a <- tabla_2x2[2, 2]  # Bajo peso + Hipertensión
b <- tabla_2x2[2, 1]  # Bajo peso + Sin hipertensión
c <- tabla_2x2[1, 2]  # Peso normal + Hipertensión
d <- tabla_2x2[1, 1]  # Peso normal + Sin hipertensión

OR <- (a * d) / (b * c)
log_OR <- log(OR)
SE_log_OR <- sqrt(1/a + 1/b + 1/c + 1/d)
IC_lower <- exp(log_OR - 1.96 * SE_log_OR)
IC_upper <- exp(log_OR + 1.96 * SE_log_OR)

4.1.6 4.2 Intervalo de Confianza 95% para la Diferencia de Medias

# El IC 95% ya está incluido en t_test (detailed = TRUE)
# Extrayamos explícitamente la diferencia de medias e IC

no_fum <- birthwt %>% filter(smoke == "No fumadora") %>% pull(bwt)
fum <- birthwt %>% filter(smoke == "Fumadora") %>% pull(bwt)

diff_medias <- mean(no_fum) - mean(fum)
se_diff <- sqrt(var(no_fum)/length(no_fum) + var(fum)/length(fum))
df_total <- length(no_fum) + length(fum) - 2
t_crit <- qt(0.975, df = df_total)

IC_lower_diff <- diff_medias - t_crit * se_diff

### 3. Prueba de Chi-Cuadrado con rstatix

`rstatix` no es la mejor opción para la prueba de Chi-Cuadrado. Aún así vamos a revisar como realizarla. 


#### 3.1 Evaluación de supuestos
Antes de realizar la prueba, evaluamos el supuesto de frecuencias esperadas:

```{r}
# El supuesto: todas las frecuencias esperadas ≥ 5
# Chi-cuadrado es robusto cuando se cumple este supuesto
table1 <- table(birthwt$low, birthwt$ht)
chisq.test(table1, correct = T)->resultado1
resultado1$expected
```

Parece que Chi-Cuadrado no es la mejor opción, aún así vamos a realizar esta prueba con rstatix

```{r}

table1 |>
  rstatix::chisq_test(correct = T) # Necesita una tabla
# Trate de siempre hacer una correcion 
```

**Interpretación de supuestos**: ¿Se cumplen? Si alguna celda tiene frecuencia esperada < 5, use la Exacta de Fisher.

#### 3.2 Prueba exacta de fisher

La alternativa es realizar la prueba exacta de fisher
```{r}
fisher.test(table1)
```

### 3.3 Tamaño del Efecto: V de Cramér

Necesita la librería `rcompanion`

```{r}
# Calcular V de Cramér (medida de asociación)
# V = √(χ² / (n × (min(k,r) - 1)))
# donde k = # de columnas, r = # de filas

rcompanion::cramerV(table1)


# Interpretación de V de Cramér (criterios de Cohen):
# < 0.1: efecto negligible
# 0.1 - 0.3: efecto pequeño
# 0.3 - 0.5: efecto mediano
# > 0.5: efecto grande
```

**Interpretación del tamaño del efecto**: 
- V de Cramér mide la fuerza de la asociación entre dos variables categóricas.
- Rango: 0 (sin asociación) a 1 (asociación perfecta).

### 3.4 Intervalos de Confianza

Para asociaciones entre variables categóricas, reportamos la **Razón de Odds (OR)** con su IC 95%:

```{r}
# Crear tabla 2x2
tabla_2x2 <- table(birthwt$low, birthwt$ht)
print("Tabla 2x2:")
print(tabla_2x2)

# Calcular OR manualmente (método frecuentista)
a <- tabla_2x2[2, 2]  # Bajo peso + Hipertensión
b <- tabla_2x2[2, 1]  # Bajo peso + Sin hipertensión
c <- tabla_2x2[1, 2]  # Peso normal + Hipertensión
d <- tabla_2x2[1, 1]  # Peso normal + Sin hipertensión

OR <- (a * d) / (b * c)
log_OR <- log(OR)
SE_log_OR <- sqrt(1/a + 1/b + 1/c + 1/d)
IC_lower <- exp(log_OR - 1.96 * SE_log_OR)
IC_upper <- exp(log_OR + 1.96 * SE_log_OR)

cat("\n=== RAZÓN DE ODDS CON IC 95% ===\n")
cat("OR:", round(OR, 3), "\n")
cat("IC 95%: [", round(IC_lower, 3), " - ", round(IC_upper, 3), "]\n")
cat("\nInterpretación: Las mujeres con bajo peso al nacer tienen",
    round(OR, 2), "veces la probabilidad de tener hipertensión\n")
cat("comparadas con mujeres de peso normal.\n")
```

# Notas Pedagógicas

## ¿Por qué rstatix?

- **Consistencia**: Mismo formato de salida para todas las pruebas.
- **Tidy data**: Resultados listos para `ggplot2` y posterior análisis.
- **Automatización**: Calcula automáticamente tamaño del efecto e IC.
- **Compatibilidad**: Se integra perfectamente con `dplyr` y `ggplot2`.

## ¿Cuándo usar ggstatsplot?

- **Comunicación**: Gráficos publicables listos de usar.
- **Docencia**: Visualiza simultáneamente datos y resultados.
- **Exploración**: Rápido testeo visual de múltiples relaciones.
- **Limitación**: Para análisis complejos, `rstatix` + `ggplot2` da más control.

## Recomendaciones

1. **Siempre explore los datos primero**: Gráficos antes de pruebas.
   - Histogramas y Q-Q plots para normalidad
   - Boxplots para comparar grupos
   - Diagramas de dispersión para relaciones

2. **Evalúe supuestos**: No asumir normalidad o homocedasticidad.
   - Shapiro-Wilk para normalidad (p > 0.05 = normal)
   - Levene para varianzas iguales (p > 0.05 = iguales)

3. **Reporte siempre**: p-valor, tamaño del efecto e IC.
   - **Mínimo**: Estadístico, p-valor, IC 95%
   - **Ideal**: Añadir tamaño del efecto e interpretación contextual

4. **Contexto clínico**: No solo significancia estadística.
   - Una diferencia pequeña puede ser estadísticamente significativa
   - Una diferencia grande puede no ser clínicamente relevante
   - Combine p-valor + tamaño del efecto + conocimiento del dominio

## Checklist para Reportar Resultados

Para cada análisis, incluya:

- ✅ Descriptivos (media, DE, mediana, rango)
- ✅ Supuestos evaluados y resultados
- ✅ Nombre de la prueba realizada
- ✅ Estadístico (t, F, H, χ², r, etc.)
- ✅ Grados de libertad (si aplica)
- ✅ p-valor (p = 0.XXX o p < 0.001)
- ✅ Tamaño del efecto (Cohen's d, η², R², etc.)
- ✅ Intervalo de confianza 95%
- ✅ Gráfico que visualice los datos y la prueba
- ✅ Conclusión en una frase clara
